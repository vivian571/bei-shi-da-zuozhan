# 📜 背诗大作战

七上古诗文必背小游戏：12 首古诗 + 7 篇文言文（名句版），单文件、离线可玩，手机浏览器打开即玩。

## 玩法

- 🧩 **挖空补字**：点字块按顺序填空，三档难度（简单 / 进阶 / 挑战），标点不挖空，填错点格子可拿回重放，2 次提示机会
- 🔗 **接龙对诗**：给上句选下句，8 题一局
- ⚔️ **双人 PK**：两人轮流背，App 当裁判——轮到的人大声背出下句，点"看答案"核对，答对得分，先到 5 分获胜

通关的篇目会点亮 ✨，进度保存在浏览器 localStorage 里。

## 本地玩

直接用浏览器打开 `index.html` 即可，无需联网、无需安装。

## 在线玩（GitHub Pages，免费）

1. 把本仓库 push 到 GitHub
2. 仓库 Settings → Pages → Build and deployment → Deploy from a branch → Branch 选 `main` / `/ (root)` → Save
3. 等一两分钟，访问 `https://<你的用户名>.github.io/bei-shi-da-zuozhan/`，手机浏览器打开就能玩

## 数据

篇目与文字对照上传的《七上古诗文必背知识汇总》PDF，古诗为全文，文言文为名句版（全文见 PDF）。
